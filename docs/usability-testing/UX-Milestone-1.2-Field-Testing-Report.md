# 📱 UX Milestone 1.2 - Field Usability Testing Report
## Elder-Accessible Interactive Prototype Testing with Indigenous Artisans

**Prepared by:** Berenice1719

**Objective:** Validate usability and identify friction points for elderly producers in rural Oaxaca

---

## 📋 Testing Summary

This document contains the field usability testing results for **Issue #2: [UX Milestone 1.2]: Elder-Accessible Interactive Prototype Usability Testing with 50 Indigenous Artisans in the Field**.

**Testing Protocol:**
- 3 core tasks evaluated with each participant
- Observation-based (no assistance provided)
- Timing and friction points recorded
- Real-world conditions (outdoor sunlight, actual devices)

---

## 🎯 Core Tasks Tested

### Task 1: Voice Recording
**Objective:** User finds and successfully records a 30-second voice note in native language

### Task 2: Digital Certificate / Origin Passport  
**Objective:** User understands the digital certificate and perceives it as valuable proof of authenticity

### Task 3: Physical QR Hang-Tag
**Objective:** User sees value in the physical tag and recognizes its purpose in preventing counterfeiting

---

## 🔍 Key Friction Points Identified

### 1. **Fear of Pressing Unknown Buttons**
- Elderly users hesitate to tap unfamiliar interface elements
- Concern: "Will this delete my data?"
- Solution: Add visual affordances (larger buttons, pulsing animations, icons)

### 2. **Sunlight Readability & Font Size**
- Small text becomes invisible under outdoor conditions
- Gray text lacks sufficient contrast with bright backgrounds
- Solution: Dark green text (#032517), minimum 16px font size

### 3. **Technical Language Creates Distrust**
- Terms like "Hash", "Blockchain", "Status" create suspicion
- Solution: Replace with community-centered language ("Sello Comunitario", "Comprobante de Origen")
